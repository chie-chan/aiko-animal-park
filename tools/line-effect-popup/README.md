# line-effect-popup — フェルト柴で「ポップアップスタンプ」「エフェクトスタンプ」を作る

既存のLINEスタンプ画像（背景透過PNG）から、LINE Creators Market の
**ポップアップスタンプ**と**エフェクトスタンプ**の申請用データを作るプログラムです。
AI・APIキー・ログインは不要で、同じ入力からは毎回同じ結果が出ます。

- **ポップアップ**: キャラが大きなフェルトのワッペンの上に「ポンッ」と飛び出し、背景で光線が回る・ハートが昇る・雨が降るなどの動きがつきます。
- **エフェクト**: トーク画面の背景いっぱいに、フェルトのハート・紙吹雪・肉球の足あと・流れ星などがつなぎ目なくループします。

背景の飾りもすべて「フェルト＋縫い目＋ふっくら陰影」で描くので、フェルト柴の世界観のまま、ほかのスタンプと並んでも見劣りしない仕上がりにしています。

## 使い方

```bash
pip install -r requirements.txt

# 1) 過去に作ったフェルト柴スタンプ（370×320 などの透過PNG）を1フォルダに入れる
#    ファイル名順（01.png, 02.png ...）に 01, 02 ... として扱います

# 2) （任意）演出の割り当て表を作って編集する
python build.py --src ./felt_shiba --out ./out --init-config
#    → out/config.json を開いて scene / preset を好みに書き換える

# 3) 作る（ZIPまで）
python build.py --src ./felt_shiba --out ./out --config ./out/config.json --zip

# 4) out/preview.html をブラウザで開いて、トーク画面での見え方を確認
```

試しに数枚だけ作るときは `--only 1,3`。
動作確認用の仮のフェルト柴は `python make_sample_shiba.py --out sample_src` で作れます（本番では使わない）。

### 演出の種類

ファイル名に「ありがと」「おはよ」「おめでと」「りょうかい」「おやすみ」「えっ」「かなし」「すき」などが入っていると、合う演出を自動で選びます。それ以外は順番に割り当てます。`config.json` で1枚ずつ変えられます。

| ポップアップ `scene` | 中身 | 既定の動き |
|---|---|---|
| `hearts` | ピンクのワッペン＋昇るハート | heartbeat（ドキドキ） |
| `sunburst` | 回る光線＋キラキラ | bounce（ぴょんぴょん） |
| `confetti` | ギザギザバッジ＋紙吹雪 | spin（くるっと登場） |
| `slam` | ドンッと着地＋星 | slam（上から着地） |
| `night` | 夜空＋月・星・Zzz | float（ふわふわ） |
| `shock` | 集中線＋「！」 | shake（ぶるぶる） |
| `rain` | 雨雲＋雨つぶ | droop（しょんぼり） |
| `flowers` | 花輪＋舞う花びら | wobble（ゆらゆら） |
| `sparkle` | キラキラ | pop（ポンッ） |

動き（`motion`）は `pop / bounce / wobble / heartbeat / spin / slam / shake / float / droop / peek` から指定可。色は `"colors": {"badge": "#FFD467"}` のように上書きできます。

## 調べた仕様（2026年9月時点・要最終確認）

LINE Creators Market の公式ガイドラインページはこの作業環境から直接開けなかったため、検索結果と解説記事から確認しました。**申請前に公式ガイドラインで最新の数値を必ず確認してください。**

| 項目 | ポップアップスタンプ | エフェクトスタンプ |
|---|---|---|
| メイン画像 | 240×240 PNG | 240×240 PNG |
| メイン（動く） | ポップアップメイン画像 480×480 APNG | エフェクトメイン画像（APNG） |
| スタンプ画像 | 8 / 16 / 24 個、最大370×320 PNG（静止画） | 同左 |
| 動く画像 | ポップアップ画像 8 / 16 / 24 個 | エフェクト画像 8 / 16 / 24 個 |
| 動く画像のサイズ | 最大480×480。縦横どちらかは480。横480なら縦320以上、縦480なら横200以上 | 同左 |
| コマ数 | 5〜20 | 5〜20 |
| ループ | 1〜3回、合計3秒以内 | 同左 |
| 容量 | 1個 1MB以下（ZIPは60MB以下） | 同左 |
| タブ画像 | 96×74 PNG | 96×74 PNG |
| 表示のされ方 | トーク画面の上に大きく飛び出す | トーク背景に流れ、吹き出しを邪魔しない |

このツールの既定値:
- ポップアップ: 20コマ（登場6コマ×60ms＋動き14コマ×110ms＋最後の余韻）＝約2.2秒×1回
- エフェクト: 14コマ×100ms＝1.4秒×2ループ＝2.8秒（つなぎ目なし）
- 1MBを超えそうなときは自動で色数を減らして収めます（report.txt に色数を表示）

### 1MBに収めるための工夫（改造するときの注意）
フェルトの質感は容量を食うので、次のルールで作っています。崩すと1MBを超えやすくなります。
- ポップアップのキャラは**ワッペン（バッジ）の内側に収まる最大サイズ**に自動調整。
- 登場後に動かすのは**バッジの内側だけ**。バッジの外の飾りは最初の3コマで出したら止める。
- キャラの動きは2コマごとに更新（`--hold 2`、コマ撮り風）。背景の粒は毎コマ動きます。
- APNGは前のコマとの差分だけを書き込む方式で保存（`lep/apng.py`）。

## ファイル構成
- `build.py` … 入口（CLI）
- `lep/felt.py` … フェルト質感の描画と合成
- `lep/shapes.py` … ハート・星・肉球・ワッペンなどの形
- `lep/popup.py` … ポップアップの背景シーンとキャラの動き
- `lep/effect.py` … エフェクトのループ演出
- `lep/apng.py` … APNG書き出し（共通パレット・差分フレーム・容量調整）と読み取りチェック
- `lep/anim.py` … イージングとタイムライン（LINE仕様の上限もここ）
- `make_sample_shiba.py` … 動作確認用の仮フェルト柴
